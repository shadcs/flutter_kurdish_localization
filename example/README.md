# Kurdish Localization Example

This example demonstrates how to use the kurdish_localization_plus package to add Kurdish localization support to your Flutter app.

## Features Demonstrated

- Setting up Kurdish localization delegates
- Configuring supported locales
- Using Material Design components with Kurdish translations
- Showing dialogs and snackbars with localized text

## Getting Started

1. Navigate to the example directory:
   ```bash
   cd example
   ```

2. Get dependencies:
   ```bash
   flutter pub get
   ```

3. Run the example:
   ```bash
   flutter run
   ```

## Key Components

- **Material Localizations**: Provides Kurdish translations for Material Design components
- **Widget Localizations**: Provides Kurdish translations for basic Flutter widgets
- **Cupertino Localizations**: Provides Kurdish translations for iOS-style components

The example shows how these work together to create a fully localized Kurdish app experience.
